# 🚀 Guia de Inicialização do Projeto

Para rodar o projeto é necessário seguir os seguintes passos:

## 1. Clonar o Repositório
Faça o clone do projeto para a sua máquina.

## 2. Configurar e Iniciar o Frontend
Abra primeiro a pasta frontend no seu terminal e execute os seguintes comandos:

```bash
cd frontend
npm i
npx expo start
```

## 3. Configurar e Iniciar o Backend
Após isso, abra a pasta backend num novo terminal e execute:

```bash
cd backend
npm i
npm start
```
