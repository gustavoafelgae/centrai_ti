# 🚀 Guia de Inicialização do Projeto

Este documento orienta o passo a passo completo para clonar, instalar as dependências e executar o projeto (Frontend e Backend) em seu ambiente local.

---

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
* [Node.js](https://nodejs.org/) (Versão estável/LTS)
* [Git](https://git-scm.com/)
* Gerenciador de pacotes `npm` (já vem incluso com o Node.js)

---

## 🔧 Passo a Passo para Execução

### 1. Clonar o Repositório
Abra o seu terminal e execute o comando abaixo para clonar o projeto para sua máquina local:

git clone <URL_DO_REPOSITORIO_AQUI>

---

📱 2. Inicializando o Frontend (Expo)Abra uma janela do terminal e siga os comandos abaixo para configurar e rodar a interface:Bash# 1. Acesse o diretório do frontend
cd frontend

# 2. Instale todas as dependências do projeto
npm i

---

# 3. Inicialize o servidor de desenvolvimento do Expo
npx expo start
💡 Dica: Após rodar o último comando, um QR Code será exibido no terminal. Você pode escanear esse código com o aplicativo Expo Go no seu celular para testar o aplicativo diretamente no aparelho.⚙️ 3. Inicializando o BackendAbra uma nova janela ou aba do terminal (mantendo o terminal do frontend em execução) e siga os passos abaixo:Bash# 1. Acesse o diretório do backend
cd backend

# 2. Instale as dependências necessárias
npm i

# 3. Inicie o servidor do backend
npm start
